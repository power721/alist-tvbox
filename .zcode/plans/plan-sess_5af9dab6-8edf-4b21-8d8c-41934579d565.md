# 网络直播弹幕(参考 pure_live)

后端连接各平台弹幕 WebSocket(协议移植 pure_live),对外提供**增量轮询接口**;spider.jar(CatVodTVSpider 的 Live.java)轮询该接口并**在播放器 Activity 上叠自绘弹幕 View** 渲染(真实时,常显无交互)。不做 web-ui 前端。支持 B站/斗鱼/虎牙/抖音(快手、CC 无弹幕协议;抖音 X-Bogus 签名失效则自动降级为空弹幕,不影响播放)。

## 一、后端 alist-tvbox

### 1. 依赖(pom.xml)
- 新增 `org.brotli:dec`(B站 brotli 解压;zlib/gzip 用 JDK;WebSocket 客户端用已有 okhttp)

### 2. 新包 `live/danmaku/`(协议移植自 pure_live,字节序/包格式照抄)
- **`AbstractDanmakuClient`**:OkHttp WebSocket 封装 — 连接、心跳定时、断线指数退避重连(≤5次)、消息回调
- **`DouyuDanmakuClient`**:`wss://danmuproxy.douyu.com:8506`,STT 文本协议(小端包、长度写两遍、结尾\0、**循环粘包拆分**),loginreq/joingroup 进房、mrkl 心跳 45s,解析 `chatmsg`(nn/txt/col)
- **`HuyaDanmakuClient`**:`wss://cdnws.api.huya.com`,手写轻量 **TarsCodec**(~200行,Head 字节/type/tag/大端/SimpleList/STRUCT 规则照抄 pure_live),进房包 uid=ayyuid,心跳为 pure_live 硬编码的 113 字节常量,uri=1400 弹幕(userInfo.nickName/content/bulletFormat.fontColor)、uri=8006 在线人数
- **`BilibiliDanmakuClient`**:`wss://{host}/sub`,**WbiSignUtil**(mixinKeyEncTab 重排+md5,照抄 pure_live)请求 getDanmuInfo 取 token/host,大端包(op7 进房 protover3、op2 心跳 60s、op3 人气、op5 消息 zlib/brotli 解压后按 \x00-\x1f 切 JSON,DANMU_MSG)
- **`DouyinDanmakuClient`**:wss://webcast100-ws-web-lq.douyin.com/webcast/im/push/v2/(完整 query 照抄),**XBogusUtil**(md5+单字节 RC4+自定义字母表 base64)、手写 **MiniProto** 读取器(PushFrame/Response/ChatMessage/RoomUserSeqMessage 四个消息的 wire-format 解析,不引 protobuf 依赖),gzip 解压 payload,needAck 回 ack,心跳 10s(hb)
- **`LiveDanmakuService`**:房间会话管理 — `platform$roomId → RoomSession`(上游 client + 环形缓冲 500 条带递增 seq + lastAccess);请求触发懒连接;每 30s 清理,60s 无轮询断开上游;`poll(platform, roomId, after)`:after 为空返回最近 30 条,否则返回 seq>after 增量

### 3. 平台 Service 暴露连接参数(Caffeine 缓存 10min)
- `HuyaService.getDanmakuArgs(roomId)` → ayyuid(复用现有 m.huya.com 抓页,从 HNF_GLOBAL_INIT/页面 JSON 提取 uid,实现时验证字段)
- `BilibiliService.getDanmakuArgs(roomId)` → realRoomId+token+host+buvid(get_info + WBI 签名 getDanmuInfo + finger/spi)
- `DouyinService.getDanmakuArgs(webRid)` → 真实 roomId id_str(复用现有 enter API);user_unique_id 随机 12 位
- 斗鱼无需参数

### 4. 接口与 DTO
- `dto/LiveDanmaku.java`(顶层类,放 dto/,自动进 Main.java 扫描):seq、userName、message、color(hex)、type(chat/online)
- `LiveDanmakuController`:`GET /live/danmaku` 与 `GET /live/danmaku/{token}`(checkToken,GET /live/** 已 permitAll),参数 platform/roomId/after,返回 `{success, platform, roomId, next, messages:[LiveDanmaku]}`;不支持的平台返回空列表
- 不改动现有 detail/play 响应(零 API 破坏)

### 5. Native image
- reflect-config.json 按既有流程重新生成(`mvn compile` + `java -cp target/classes cn.har01d.alist_tvbox.Main`)

### 6. 测试与验证
- 单测:Douyu STT 编解码+粘包、Bilibili 包格式+WBI 签名(固定输入对拍 md5)、Huya Tars 编解码、Douyin X-Bogus(注入固定随机源)/MiniProto
- 起 test profile 实例(45680),用真实房间 curl 轮询接口验证四平台出弹幕

## 二、spider 端 CatVodTVSpider

### 7. 新类 `com.github.catvod.spider.LiveDanmaku`
- 轮询线程(daemon,2s 间隔,OkHttpUtil)拉增量接口
- application context 注册 `ActivityLifecycleCallbacks` 跟踪前台 Activity,主线程 Handler 往 content view 叠 **`DanmakuOverlayView`**(自绘 View:TextPaint 白字黑描边、4 轨道滚动、postInvalidateOnAnimation 驱动、同屏上限 ~40 条、出屏回收;不 focusable、不拦截遥控器/触摸)
- 生命周期:playerContent 新房间时 restart(移除旧 View 换房间);前台 Activity destroy 时停轮询移 View;`Live.destroy()` 全停

### 8. `Live.java` 修改
- `detailContent` 记录 url→房间(platform$roomId)映射(所有线路所有集)
- `playerContent` 查映射:命中则启动弹幕(主路径:进详情→播放 100% 覆盖);未命中(FongMi 历史记录直接播放等)不显示弹幕,第一版可接受,后续可加后端 resolve 端点

### 9. 构建
- `./build.sh` 打包 spring.jar + md5 拷回 alist-tvbox/src/main/resources/static/

## 三、风险
- 抖音 X-Bogus 可能过时 → 连不上时空弹幕,不影响播放
- 虎牙 ayyuid 页面字段实现时验证
- 叠 View 需不干扰 FongMi 焦点/按键(自绘 View 默认不消费输入)
