# RC11 取链返回值诊断

## 本轮范围

爱看原候选的 C10 已恢复，R01 仍为 `PLAYER_URL_INVALID`。旧回执只记录 `playerRouteKind=other` 和地址摘要，不能区分不透明选集标识原样回传、相对地址、编码地址或返回类型错误。本轮补平台证据，不人工修改该爬虫，也不更改成功门槛。

`playerContract` 绑定本次成功返回的详情与取链调用，记录选集标识及返回值的形态、返回类型/字节数、是否原样回传、声明的解析模式和空白/片段/用户信息/主机存在标志。不保留原始标识、地址、请求头或 Cookie。后端校验对应调用、先后关系及字段枚举；普通模型、加强诊断和管理页使用同一脱敏投影。

编码识别只在最多 8192 字符内辨认百分号/Base64 地址前缀，不执行解码结果、不发起新请求、不把相对地址补成绝对地址，也不把识别结果当作可播证明。失败状态、源特定画像、媒体取证门槛和原三轮维修账本不变。
