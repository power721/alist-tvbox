# 上游贡献范围

当前上游 PR 以[贡献分层记录](github-review-2026-11-19.md)为准。早期本地双模式补丁包保留在项目开发资料中，不是本 PR 的安装或构建入口。

正式审阅与合入按[合入指南](merge-guide.md)执行：先合宿主 #1095，再合模块 #1096，构建单套 AT Web，并在冷备副本上验证权限、迁移与执行器。

## 分层

1. 宿主合同：T4 装载身份和可选插件写入协调，单独前置 PR，可先审阅。
2. 隔离执行器：受管源码、网络观察和清理。
3. 控制面：巡检、诊断、模型候选、复验和持久发布队列。
4. AT 工作台组件：`web-ui/src/maintenance`，使用 AT 的路由、登录和前端依赖。
5. 内置适配：显式 maintenance-embedded profile、独立维护迁移历史。

本 PR 不交付独立 HTML、iframe 页面、独立工作台前端包、独立服务启动类或独立工作台容器。仅 AT `/#/maintenance` 入口。控制面保留的 Spring 启动与登录配置只存在于测试目录，不是生产入口。

## 审阅包

`prepare_upstream_review.py` 只读当前源码，按上述责任范围生成有序审阅单元；`select_sources` 选取 AT 组件及其测试，不再选取 plugin-maintenance/web-ui 或独立启动器。

需要从当前上游基线重新制包时，应核对固定基线并显式处理删除项；不得把旧双模式增量包盲接到新的内置范围，不覆盖旧包或原开发区。

## 验证

[构建与验收](build-and-acceptance.md)给出当前命令。前端只构建一次 AT Web；内置 profile 测试复用真实 AT 会话及数据库合同，不调用真实模型、不运行站点爬虫。

公开源码不包含站点脚本、连接凭据、活动数据库、私有运行回执或二进制镜像。未验项目、上游检查状态与实际维修结果分开记录，不创建稳定 Release。
