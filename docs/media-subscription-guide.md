# 追剧订阅使用指南

订阅一部剧,系统自动追更:定时检查资源更新、链接失效自动换源(播放进度不断)、缺集自动从多个分享补齐,还可自动转存到你自己的网盘,彻底告别"收藏夹里的链接全失效"。

## 快速上手

### 1. 创建订阅

管理页 →「追剧」→ 新建订阅:

- **条目链接**(最省事):直接粘贴条目链接,点「解析」自动识别并回填元数据绑定、剧名、季与总集数。支持:
  - 豆瓣 subject、TMDB tv(含 `/season/2` 自动填季)、Bangumi subject、腾讯视频 cover(按 id 直取官方分集);
  - **B 站番剧/动漫/电视剧播放页**(含 ss/ep 的链接;media 页为前端渲染不支持,b23.tv 短链会自动展开)→ 按剧名优先绑定 Bangumi(番剧)或豆瓣;
  - **优酷剧集页 / 爱奇艺剧集页** → 按剧名优先绑定豆瓣(页面为前端渲染解析失败时会有明确提示,改用关键词绑定即可)。
- **剧名 / 搜索词**:展示名与搜索关键词(默认同名)。资源命名与官方名差异大时可填别名。
- **元数据条目**(强烈建议绑定):搜索并选择豆瓣 / TMDB / Bangumi / 官方平台(腾讯/优酷/爱奇艺)条目。绑定后自动获得:
  - 官方总集数与已播集数(缺集检测的权威依据);
  - 播出日程(按"播出后 15 分钟起连查"调度,不用等固定周期);
  - 官方完结状态(达标自动标记完结);
  - 封面与下一季探测。
  - 部分源失败会在搜索框下方提示原因(如 TMDB 需自备可达网络/密钥)。
- **季**:追第几季。
- **资源模式**:
  - **挂载追更**(默认):分享固定挂载在 `/追剧/{订阅}` 路径,失效自动从候选池换源,免网盘账号;
  - **自动转存**:新集自动复制到你自己网盘的 `/追剧/` 目录(见下)。
- **筛选条件**:盘类型偏好(可排序)、清晰度、包含/排除关键词、单集下限/上限(MB)。留空的维度沿用用户默认偏好(页头「通知」旁设置项待扩展,当前在订阅内设置)。
- **资源评分**(自动,「预览」可见打分明细):除新近度/清晰度/盘偏好外,还感知账号与资源形态 —— 标题含「免会员」加分;该盘已配置账号加分、**VIP 账号(页头「通知」里勾选)大幅加分**;追更中的订阅遇到 115 分享与「全N集」完结包会减分(它们不会持续更新,完结订阅则不受影响)。

### 2. 查看与播放

- 列表显示进度(`已更新 12/24 集 · 缺第 5-6 集`)、候选源数、下次检查/下集播出时间。
- 「集数」抽屉:每集是否已有、来自主源还是补缺源。
- 「候选源」抽屉:各资源评分/有效性,可手动"启用"换源(换源后播放地址不变,观看进度保留)。
- TVBox 端:订阅 token 对应的 `/tg-search` 源里,首页分类第一位是「我的追更」。

### 3. 一键订阅(不必先建订阅)

- **web 搜索页**(盘搜/电报频道):结果行「追更」按钮 —— 当前资源直接成为主源(订阅即所见)。
- **播放记录页**:历史行「追更」按钮,按剧名订阅。
- **TVBox**:播放 TG 搜索资源时,详情页末尾有「追更」操作组(需 spider.jar ≥ 当前版本),订阅后自动回到第一集继续播。

## 自动转存(多网盘)

选择「自动转存」模式后,可**多选网盘账号**(夸克/115/阿里/UC/百度等任意已配置账号的组合):

- 每小时自动对比源覆盖与各目标网盘已有集,**只增量复制缺失集**;
- 每个网盘独立成败、独立事件记录;**全部目标都失败**才自动降级为挂载模式(追更不中断);
- 每日转存量有上限(默认 20 次,`app.subscription.max-transfers-per-day`),防配额/风控;
- 完结 N 天后自动释放转存文件(默认关闭;「通知」对话框里配 `msub_archive_days`)。

## 追更机制(为什么省心)

- **三级巡检**:优先重新列主源目录发现新集(零搜索开销)→ 主源失效从候选池秒级换源 → 停滞多轮才触发搜索,且无更新自动退避(最长 24h)。
- **缺集补搜**:官方已播而本地缺的集,自动探测候选池并临时挂载验证,覆盖缺口的资源挂为"补缺源",播放列表按集号合并(主源优先);主源日后补齐,补缺源自动退役。
- **候选池**:每次搜索保留 Top 5 有效候选,换源不用现场搜索。
- **4K 升级提醒**:主源非 4K 而池中出现 4K 完整源时提醒(不自动替换,候选源里手动启用)。

## 通知与维护

- **播出时间轴**:页首横条展示**昨天到未来 7 天**每天更新的订阅与媒体播出时间(如 `19:00 凡人修仙传 第188集`),今天高亮;数据来自绑定元数据的分集播出日期,每日随巡检刷新。未绑定元数据的订阅退化为只显示下集播出时间。
- **事件流**:新集/换源/补缺/转存/错误全部记录,列表「动态」抽屉查看;页头「今日/近日更新」收件箱聚合近 3 天。
- **Telegram 通知**(可选):页头「通知」里填 Bot Token 与 Chat ID,新集/错误/完结/转存完成会推送。
- **批量操作**:全选/反选 + 批量检查/暂停/恢复/删除。
- **导出/导入**:JSON 格式,重装迁移或设备间复制(同名同季自动跳过)。

## 常见问题

**Q: 元数据搜索只有豆瓣有结果?**
A: 各源独立性失败会即时提示原因。常见:TMDB 接口在部分网络不可达(可配自备 `tmdb_api_key`);官方平台只返回腾讯本站在播条目;Bangumi 偏动画/日剧。豆瓣始终有本地库兜底。

**Q: 搜索结果封面有的不显示?**
A: 封面已统一走后端 `/images` 代理(TMDB/Bangumi 图床直连可能被墙或防盗链)。仍不显示多为原条目本身无图。

**Q: 夸克分享有效,但其中某一集被和谐了怎么办?**
A: 两种形态都已处理:被和谐的文件从分享列表里**消失**的,巡检直接视为缺集,自动从其他分享补上;文件**还列在目录里但实际取不了**的(点开播放失败),在自动转存模式下会被转存校验发现 —— 系统把该集登记为该源的"损坏集"(7 天过期自动重试),集数统计与取源立即跳过它,下一轮就会从其他分享补齐这一集;换源时登记自动清空。纯挂载模式下无法感知"列表在但播不了"(播放失败发生在播放器端),遇到这种情况建议开启转存模式,或手动在候选源里换源。

**Q: 目录名里的 `[dbid-x]` / `[tmdbid-x]` / `[bgmid-x]` 是什么?**
A: 绑定元数据后,订阅目录与转存目录会带上豆瓣/TMDB/Bangumi 的条目 id:全局唯一(同名剧/不同剧不怕撞名),Emby/Jellyfin/tinyMediaManager 等刮削器也能按 id 精准匹配元数据。仅对新建订阅生效(存量订阅目录不改名,固定路径不动);转存目录若为旧命名,下次转存时会自动原地改名迁移,不重复拷贝。

**Q: 每一集可以来自不同网盘的分享吗?**
A: 可以,这正是缺集补搜 + 多源合并的形态:第 1 集来自夸克分享 A、第 2 集来自夸克分享 B、第 3 集来自百度分享,播放列表按集号合并成单一入口,你感知不到背后有几个分享。分享直连播放**不需要**网盘账号;若想彻底免疫分享失效,选自动转存模式并配置网盘账号 —— 已转存的集会**优先从你自己的网盘播放**(逐集生效:哪集转好了走哪集,没转好的继续走分享),跨盘复制由内嵌 AList 完成(夸克分享 → 百度盘也可以)。

**Q: 为什么出现了 `/追剧/xxx-补1`、`-补2` 这样的挂载?**
A: 旧版本的补缺源曾与主源并排展示;现在补缺源统一收纳在内部目录 `/追剧/.sources/` 下 —— **`/追剧/` 里每部剧只有一个文件夹入口**,多个分享资源在播放列表里按集号自动合并(主源优先),你不需要关心背后有几个分享。旧挂载会在下轮巡检自动迁移。主源日后补齐对应集数后,补缺挂载自动退役删除;每订阅最多 3 个补缺挂载(`app.subscription.max-gap-mounts`)。

**Q: 换源会丢观看进度吗?**
A: 不会。订阅固定挂载路径,换源只替换路径背后的分享,播放地址与历史记录不变。

**Q: 单集上限怎么配?**
A: 新建/编辑订阅的筛选条件里「单集上限(MB)」,0 为不限;超限文件不计入集数、不转存(用于过滤捆绑包/花絮合集里的异常大文件)。

**Q: 转存目标支持哪些网盘?**
A: 任意已在「账号」页配置的 DriverAccount 均可,且可多选同时转存;跨盘复制由内嵌 AList 完成,源(分享)与目标(账号盘)类型不必相同。
